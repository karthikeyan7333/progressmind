# 🧠 ProgressMind – Personal Habit Tracker

**Build better habits. Track your progress. Become your best self.**

ProgressMind is a modern, user-friendly habit tracking application designed to help users build consistency, manage daily routines, and achieve personal goals.

## ✨ Features

- 🔐 **User Authentication** – Login and signup functionality.
- 📅 **Habit Calendar** – Track daily habits through an interactive calendar.
- 📊 **Progress Analytics** – Visualize your habit performance and consistency.
- 📆 **Weekly & Monthly Tracking** – Monitor your progress over different time periods.
- 🎯 **Habit Management** – Create, manage, and track personal habits.
- 😊 **Interactive Experience** – Simple and engaging user interface.
- 📱 **Responsive Design** – Access your habit tracker across desktop and mobile devices.

## 🛠️ Tech Stack

- React.js
- TypeScript
- Vite
- CSS

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/karthikeyan7333/progressmind.git
```

### 2. Navigate to the project

```bash
cd progressmind
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🎯 Project Goal

The goal of ProgressMind is to make habit tracking simple, encourage consistency, and help users understand their personal growth through meaningful progress insights.
